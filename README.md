# BotView

## 🚀 Instalación y ejecución en Windows

### 📦 Requisitos

- Python 3.x instalado
- Google Chrome instalado
- ChromeDriver (compatible con tu versión de Chrome)
- Los requerimientos de Python (se instalan con el comando `pip`)

### ⚙️ Pasos de instalación

1. **Clona el repositorio y entra a la carpeta del proyecto:**
   ```sh
   git clone https://github.com/GatoArtStudio/BotView.git
   cd BotView
   ```

2. **Instala los paquetes requeridos:**
   ```sh
   pip install -r requirements.txt
   ```

3. **Instala Google Chrome:**
   - Descárgalo desde: https://www.google.com/chrome/

4. **Descarga ChromeDriver:**
   - Busca la versión de Chrome que tienes instalada.
   - Descarga ChromeDriver compatible desde: https://chromedriver.chromium.org/downloads
   - Descomprime el ejecutable y:
     - Añádelo a tu variable de entorno `PATH`, **o**
     - Coloca el archivo `chromedriver.exe` en la carpeta del proyecto.

5. **(Opcional) Descarga una lista de proxies:**
   - Puedes obtener una en: https://free-proxy-list.net/
   - Si no quieres usar proxy, simplemente responde "n" cuando el programa te pregunte.

6. **Ejecuta el bot:**
   ```sh
   python main.py
   ```

## 🚀 Installation and running on Windows

### 📦 Requirements

- Python 3.x installed
- Google Chrome installed
- ChromeDriver (matching your Chrome version)
- Python requirements (installed via `pip`)

### ⚙️ Installation steps

1. **Clone the repository and enter the project folder:**
   ```sh
   git clone https://github.com/GatoArtStudio/BotView.git
   cd BotView
   ```

2. **Install required packages:**
   ```sh
   pip install -r requirements.txt
   ```

3. **Install Google Chrome:**
   - Download from: https://www.google.com/chrome/

4. **Download ChromeDriver:**
   - Check your installed Chrome version.
   - Download the matching ChromeDriver from: https://chromedriver.chromium.org/downloads
   - Extract the executable and:
     - Add it to your system `PATH`, **or**
     - Place `chromedriver.exe` in the project directory.

5. **(Optional) Download a proxy list:**
   - You can get one at: https://free-proxy-list.net/
   - If you don't want to use proxies, just answer "n" when prompted by the script.

6. **Run the bot:**
   ```sh
   python main.py
   ```
